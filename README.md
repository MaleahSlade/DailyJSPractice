Daily JavaScript Practice

A daily habit repo for learning JavaScript by writing small functions. Each day has three short exercises in the same format (function name, task, parameters, return value, and an example to test against), and the difficulty rises each week: single-parameter basics first, then loops and multiple parameters, arrays and strings, objects, and eventually recursion. I write each solution by hand, test it against the example, and review it for bugs before moving on.

Solutions are organized by week and day (for example, week-1/day-02.js) and run with Node.js
